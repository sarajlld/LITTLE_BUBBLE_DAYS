# 작은 비눗방울의 날 (Little Bubble Days)

## 프로젝트 소개

**작은 비눗방울의 날**은 어린 시절 욕조에서 비누로 거품을 만들며 놀던 기억에서 출발한 웹캠 기반 인터랙티브 게임입니다.

어릴 때는 작은 비눗방울 하나만으로도 즐거웠지만, 어른이 되면서 그런 사소한 즐거움을 잊고 살아가곤 합니다.

이 게임은 손동작을 통해 비눗방울을 직접 터뜨리며, 잠시 어린 시절의 순수한 즐거움과 추억을 다시 느낄 수 있도록 기획했습니다.

## 게임 진행 방식

1. **어린 시절로 돌아가기**  
   카메라 사용을 허용한 뒤, 이름과 돌아가고 싶은 어린 시절의 나이를 입력합니다.

2. **비누로 거품 만들기**  
   손가락을 움직여 비누를 문지르고 비눗방울을 만들어 냅니다.

3. **첫 번째 게임 — 내 비눗방울**  
   원하는 비눗방울 색깔을 선택하고, 엄지와 검지를 붙이는 동작으로 자신의 색깔 비눗방울을 터뜨려 점수를 얻습니다.

4. **두 번째 게임 — 반대 비눗방울**  
   이번에는 규칙이 반대로 바뀝니다. 자신의 색깔 비눗방울을 터뜨리면 10점이 감점되고, 특별한 모양의 비눗방울을 터뜨리면 10점을 얻습니다. 일반 비눗방울은 점수에 영향을 주지 않습니다.

5. **마지막 게임 — 커다란 비눗방울**  
   손가락을 벌리고 오므리는 동작을 반복하여 커다란 비눗방울을 키웁니다. 마지막에는 비눗방울이 터지며 작은 비눗방울들이 화면 전체로 퍼집니다.

6. **최종 결과 확인**  
   게임이 끝나면 총점과 다른 플레이어들 사이에서의 순위를 확인할 수 있습니다. 최고 기록은 저장되며, 다시 도전할 수 있습니다.

## 인터랙션 방식

Google MediaPipe Hand Landmarker를 활용하여 웹캠으로 손동작을 인식합니다.

- **메뉴 선택:** 검지를 버튼 위에 약 0.25초 동안 유지
- **비눗방울 터뜨리기:** 엄지와 검지를 붙이는 동작(Pinch)
- **게임 조작:** 일시정지, 이어 하기, 다시 시작 및 이전 단계로 이동 가능

## 기획 의도

이 프로젝트는 단순히 높은 점수를 얻는 게임이 아니라, **어린 시절의 작은 행복을 다시 경험하는 것**에 의미를 두었습니다.

마우스 대신 손으로 직접 비눗방울을 터뜨리는 인터랙션을 통해 실제로 비눗방울을 가지고 놀던 감각을 표현하고자 했습니다.

손그림 느낌의 파스텔 색감과 부드러운 비눗방울 연출을 활용하여 따뜻하고 순수한 어린 시절의 분위기를 전달하는 것이 이 프로젝트의 목표입니다.
